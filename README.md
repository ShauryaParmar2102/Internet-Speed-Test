# 🌐 Internet Speed Test

A simple desktop Internet Speed Test application built with **Python and Tkinter**.

The application allows the user to test their internet connection and displays their **download speed, upload speed, ping, and connection quality**.

## ✨ Features

- 📥 Tests download speed
- 📤 Tests upload speed
- 📡 Measures ping
- 🚦 Describes the quality of the internet connection
- 🔢 Animated speed results
- 🖥️ Simple Tkinter graphical interface
- 🧵 Uses threading to run the speed test without freezing the interface

## 🛠️ Technologies Used

- 🐍 Python
- 🖼️ Tkinter
- 🌐 speedtest-cli
- 🧵 Threading

## 🚦 Connection Quality

The application uses the download speed to give the connection a simple description:

- Below 10 Mbps — Slow Connection
- 10–49 Mbps — Good Connection
- 50–99 Mbps — Very Good Connection
- 100+ Mbps — Very Fast Connection

## 📥 Download the Project

1. Click the green **`<> Code`** button at the top of the repository.
2. Click **Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the extracted project folder.
5. Install the required package:

   `pip install speedtest-cli`

6. Run the application:

   `python internet_speed_test.py`

7. Click **START** to test your internet speed.
